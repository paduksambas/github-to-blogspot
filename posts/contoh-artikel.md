# Halo Dunia! 🚀

Ini adalah contoh postingan blog yang diterbitkan secara **otomatis** langsung dari repositori GitHub menggunakan **GitHub Actions**.

## Keunggulan Menulis Blog di GitHub:
1. **Format Markdown yang Rapi:** Menulis artikel jadi sangat cepat tanpa perlu editor web yang lambat.
2. **Version Control:** Setiap revisi tulisan tersimpan aman dalam riwayat commit Git.
3. **Sistem Fallback Otomatis:**
   - Dicoba terlebih dahulu lewat **Google Blogger API v3**.
   - Jika terjadi kendala pada API atau kuota, otomatis dialihkan ke **Mail-to-Blogger**.

    print("Halo dari GitHub ke Blogspot!")
