📖 Alur Mudah Pembaruan (Update) Template Mingguan

Anda dapat memperbarui tampilan foto kartu berita, karakter presenter reels, maupun layout story setiap minggu dengan langkah mudah berikut:

1. Update Presenter Reels Singa Ganti file foto karakter di folder assets/ (misal: lion_anchor_speaking.jpg) dengan foto presenter baru pilihan Anda.
2. Update Layout Kartu Berita (4:5) Warna, logo, dan gaya font diatur terpusat di skrip scripts/generate_facebook_post.py pada fungsi generate_facebook_news_card.
3. Update Layout Facebook Story (9:16) Struktur header, tinggi foto, dan penempatan teks diatur pada fungsi render_story_card_916 di file scripts/facebook_story_publisher.py.
4. Push ke GitHub Jalankan git commit dan git push origin main. Seluruh workflow otomatisasi langsung menggunakan template terbaru Anda pada jadwal tayang berikutnya!
